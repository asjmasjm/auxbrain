# AuxBrain 0.15.2：知识检索与用量

## 跨论文知识检索

1. 打开个人知识库，点击“跨论文知识检索”。
2. 输入关键词，按 Enter 或点击搜索图标提交。输入过程中不发送查询。
3. 结果按论文分组，显示已确认知识、适用条件及原文依据。总数和分页使用后端返回的 `total`。
4. “打开论文卡片”进入原有卡片和审核流程；左上角“返回检索结果”保留关键词和结果页。
5. 展开原文依据，点击“跳转原文”使用原有快照校验和定位流程。缺少位置时先打开卡片关联本地原文。

空结果只表示“未找到匹配的已确认知识”，不代表论文没有相关内容。后端的共同关键词关联不作为知识结论或实体关系展示。
检索仅访问本地只读接口，不调用 LLM，不新增知识或审核记录。

## 用量

论文详情底部增加默认折叠的“用量”。展开后才请求数据，显示问答、整理、审核和已有历史整理 tokens，以及整理复用次数。

- **已记录 tokens**：已有回执中的用量，不是完整账单。
- **部分用量未记录**：存在未知用量或记录不完整；不会把缺失阶段自动填为零。
- **当前数据库尚未启用成本记录**：没有可用追踪，不展示“零成本”。
- **整理复用次数**：只计次数，不推算节省金额。

用量只在展开和手动刷新时读取，不持续轮询。

## 整理复用

任务完成且回执为 `receipt.mode = reused_build` 时显示“已复用整理结果”，无需新增操作。
同一次请求的网络重试仍沿用原 key，新问题使用新 key。前端不会为了复用反复提交历史 key。

## 服务兼容与升级

两个入口需要带以下接口的新 Companion 构建：

- `GET /api/v1/dossiers/knowledge?q=Bridge&limit=20&offset=0`
- `GET /api/v1/dossiers/{work_id}/economics`

仅看服务版本 `0.11.2` 不足以判断支持情况，原始构建没有这些接口。
旧服务返回 404/501 时相应查询禁用并提示更新；旧版检索路由返回 `400 Unknown work_id` 也按不支持处理。
更新并重启服务后可点击“更新服务后重试”。其他卡片和审核功能不受影响。

本次插件安装包不附带旧 Companion，避免误以为旧运行包支持新接口。后端更换和个人库迁移需另行确认、备份并检查空闲任务。
前端文件替换后，在“设置 → 第三方插件”中关闭再开启 AuxBrain；只关闭侧栏不会重载。
