# AuxBrain 0.14.2：原文关联结果

点击论文知识条目的“关联本地原文”后，会先显示读取和保存进度，再核对当前这条证据的原文位置。
完成后，面板保留结果提示，并显示一次通知；无需通过按钮是否消失来猜测成功与否。

- **本地原文关联成功**：服务返回当前证据的唯一可用位置，显示文件及位置，提供“跳转已关联原文”。关联成功不等于已完成高亮；跳转时仍会检查本地文件是否与快照一致。
- **当前证据尚未定位**：文字无法匹配、重复位置不唯一，或原文版本发生变化，会显示对应原因，不假报成功。
- **关联已保存，但结果核对失败**：保存请求已经完成，但后续读取失败。点击“重新核对结果”只读取结果，不重复提交关联。
- **原文关联未确认**：读取文件或提交关联时发生错误。显示具体错误，允许只读核对；网络异常不能直接认定为“完全没写入”。

结果提示可通过右上角关闭图标收起。进入其他论文或返回列表时清除，避免跨论文混淆。
页面中其他未定位证据不会被当前一条证据的成功状态代替。
