# AuxBrain 0.18.2：认可或修正

配套 Companion 0.13.2。回答区只有一组操作，展开原文依据后位置和逻辑不变。

## 回答正确

直接点击“认可并入库”。无需写理解，也不需要去论文卡片再确认一次。

按钮先显示“正在入库”，成功后变为“已认可入库”；“查看知识”打开对应论文卡片。卡片中的内容标为“用户认可的回答”，保留提问、回答、原文依据和人工认可记录。

这一步不会调用 LLM，也不会把算法额外推断的关系一并自动确认。已有待确认条目仍保留自己的状态，因此待确认数量不一定归零。原文版本变化或没有可核对的引用证据时，会提示未入库，不能把缺少证据当作成功。

## 回答需要修改

点击“我要修正”，输入框会带入原回答，只修改不准确的部分即可。核对原文后，点击“解析关系”，检查结果，再“确认并入库”。原有 HIL 审核流程保留，不会自动把修改前的回答认可入库。

“返回回答”退出纠正，未提交的修改不会入库。已经认可入库的回答应通过“查看知识”进入卡片修改或撤回，不在回答页并行发起另一条冲突写入。

## 查看依据与异常处理

“查看AuxBrain回答依据”仅展开证据，不代表认可，也不会入库；默认 TOP-1，可调整数量。“收起依据”直接折叠，不增加一层菜单。

写入期间禁止重复点击并与提问互斥。网络中断时点击“重试入库”，会沿用同一次操作标识；即使服务器已经保存但响应丢失，也不会重复新增。结果尚不明确时暂不允许同时纠正，避免对同一回答做相互冲突的写入。

旧后端不支持该安全接口时，认可按钮禁用并提示所需版本，不回退到旧点赞自动确认关系的实现。

## 更新

先等待任务空闲并备份数据库，更新并重启 Companion 0.13.2；保留原数据目录。更新插件 0.18.2 后，在 Obsidian 第三方插件设置中关闭再开启 AuxBrain。仅关闭侧栏不会重载。

本版本地打包不表示已经发布到 GitHub；仍为 GitHub/BRAT Beta，不进入正式市场。Companion 为未签名 Windows 程序，SmartScreen 风险和许可见运行包说明。
