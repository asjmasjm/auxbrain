# AuxBrain 0.19.2 中文版

本版本为测试版，配套本地服务 0.13.2。GitHub 仅使用测试分支和草稿 Release，不执行 Publish，
不提交正式插件市场。草稿不是 BRAT 自动更新源，本机使用已验证的文件直接部署。

## 回答正确时

回答下面点击“同意并入库”。无需重新写理解，也无需再进入论文卡片确认。
按钮显示“正在入库”，成功后变为“已同意入库”；“查看知识”打开对应论文。
本操作认可的是屏幕上的回答及其原文依据，不会连带认可尚未核对的推导关系。

## 查看提炼的关系

“查看AuxBrain回答依据”内显示支持原文，以及本次提问已关联的实体关系。
论文卡片和“核对结论”页也会显示“主体 → 中文关系 → 关联实体”。
肯定、否定、不确定均保留，不将否定关系画成肯定结论。
点击实体框可展开该端的主体或实体名称。

后端只有文字结论时，显示“文字结论 · 尚无结构化实体关系”。
这不是加载成功但隐藏了图谱，也不表示论文没有关系；当前记录尚未提供可绘制的结构化关系。
本轮前端不额外调用 LLM，不从共现关键词虚构连线。

## 核对与修正

“核对结论”页顶部提供“同意并入库”和“我要修正”。
结论正确时直接同意，只有一次提交；后台会检查版本与冲突。
有误时点击“我要修正”，修改现有结论并“保存修正”。保存后的替代条目仍待核对，
审核正确后点击“同意并入库”。取消或返回不会保存修正。
纯原文摘录仍使用“写下我的理解”，避免把尚未提炼的原文误认作关系结论。

文字修正可能改变原来的关系，因此不会继续显示旧关系连线；其他适用条件和原文保留。
连接中断时，先读取最新入库状态，不能把未知结果当作成功或再次盲目提交。

## 语言与界面

- 当前菜单使用中文，包括“仅 LLM”“接口密钥”“令牌用量”“前 1 条”。
- 论文原文、原始回答内容和模型、数据集等专有名称不做机械翻译。
- 审核页按钮、选项、输入框和折叠标题统一为 14px，元信息保留次级字号。
- 后续英文版应独立设置界面语言；本版本不混放中英文推荐说明。

## 部署注意

更新前确认前台和后台任务空闲，并备份原数据库。继续使用原数据库路径，不删除个人知识库。
直接认可回答需要本地服务返回 `answer_approval_version=1`；旧服务下该按钮禁用并提示更新。
重载插件需在 Obsidian 设置的第三方插件中关闭再开启 AuxBrain，关闭侧栏不等于重载。

版本号规则从本轮后生效：大功能更新第二位，小功能、修复或重新编译更新第三位。
例如 0.19.2 的大功能后续为 0.20.2，小功能后续为 0.19.3。本轮保留已验证版本 0.19.2。
