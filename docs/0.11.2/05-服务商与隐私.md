# AuxBrain v0.11.2 服务商与隐私

本文更新软件行为说明，不是新的法律意见或供应商授权。套餐条款审阅沿用 2026-09-28 的记录；使用前应阅读官方当前条款并自行核实适用范围。

## 三类接入选项

| 选项 | 需要注意 |
| --- | --- |
| DeepSeek 官网 API | 使用个人有权使用的开放平台账户，遵守其协议、数据和计费规则 |
| 火山 Coding Plan | 论文问答、HIL 及无人值守后台整理的套餐适用范围仍待供应商确认 |
| 腾讯 Token Plan | 可选适配器不等于授权；既有条款审阅记录包含自定义应用后端等限制，未经确认不得把本地后端视作自动豁免 |

官方条款和更多技术说明见随包的 [PROVIDER-USAGE.md](PROVIDER-USAGE.md)。模式与 Key 配置页的 **声明** 可随时打开；关闭声明不改变当前选择，也不构成免责声明式的授权。

模型是否可用取决于账户与当前目录。Auto 表示供应商路由，不保证固定模型。适配器不自动购买套餐，不在认证失败时切换供应商，也不静默切到普通按量付费接口。

## Key 与费用

每人使用自己的 Key。保存与测试分开：保存只写本机凭据，测试会发送短提示并可能消耗额度；正式提问会发送所需论文上下文。一次 AuxBrain 提问可能多次调用模型，重试也是新的费用或配额消耗。

Key 不写进插件的 `data.json`，腾讯凭据与其他供应商分开保存。不应公开源码配置、凭据、截图或日志中的 Key；已泄露的 Key 应在服务商后台撤销或轮换。

## 哪些数据在本地，哪些会联网

个人 SQLite 数据库、已记录的历史、知识和审核事件保留在本机。插件通过回环接口访问 Companion；Companion 在 LLM 工作流中把问题及必要论文上下文发给所选供应商。

本地建库不意味着所有处理离线。不要上传无权披露的论文、商业机密或个人信息。发布包不包含开发者数据库、论文或 API Key。

## 后台整理是独立配置

默认档案整理在本地生成摘录候选。命令行的 `--dossier-llm` 才启用 DeepSeek 后台整理与证据审核，可能发送问答及证据内容并消耗额度。它不跟随前台供应商下拉框，也不会因升级 0.11.2 自动启用。

开始使用新的后台云端工作流前，应另行确认授权、费用和数据发送范围。
