AuxBrain v0.11.2 Beta 更新说明

此版本把之前在本地 0.9.1 上持续完成的前后端更新汇总为新的配套版本。插件、Companion、下载入口和文档统一使用 0.11.2；算法和数据库结构不因改版本号而被清空或重置。

主要变化

  • 包含当前后端 v17 段落预算证据选择器及请求级计时诊断，不回退到 v16。
  • 个人知识库使用论文卡片，包含基本信息、八维结构化知识和提问贡献，保留旧知识图谱入口。
  • 核对流程区分原文摘录与知识表述，折叠长段、消除重复原文，明确提炼、确认、修改和撤回操作；新表述不自动确认。
  • 对接 schema 3 的证据位置持久化、论文版本核对、人工审核与同论文已确认记忆。
  • 增加未载入文档的右键入口，明确卡片原文证据与本地文件关联入口。
  • 证据筛选按轮次细分真实等待、首段、接收、本地整理耗时；非流式接口使用合并阶段。
  • 包含腾讯可选模型适配与三家供应商声明，Key 保存和连接测试分离。
  • 更新全套安装、升级、使用、知识库、隐私、故障排查及版本核对文档。

升级提醒

两个组件一起更新。停止旧服务并备份 profile，启动新版，再关闭并开启插件。保留原数据库路径。GitHub tag 为 0.11.2，产品展示可写 v0.11.2。

保留限制

Windows 便携程序仍未签名；通过 GitHub/BRAT 测试，不进入正式市场。供应商条款与账户限制需要用户确认。没有增加扫描件 OCR、VLM 图表摄取或自动联网补齐元数据。计时细化是可观测性改进，不是承诺每次提问更快。

公开文件不包含算法源码、个人数据或用户论文截图。文档图示使用虚构数据，未伪装成真实问答。旧版文档与备份保留，但本次安装应以本版配套文件及其 SHA256SUMS.txt 为准。
