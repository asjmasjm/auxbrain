AuxBrain v0.11.2 版本核对与故障排查

核对四个版本

项目 本版值
插件 manifest / package / release tag 0.11.2，GitHub tag 不带 v
Companion 服务与文件版本 0.11.2 / 0.11.2.0
API 协议 1

论文档案 schema / 细分进度协议 3 / 1 
Invoke-RestMethod http://127.0.0.1:8795/api/v1/health | ConvertTo-Json -Depth 5

检查 service_version、api_protocol_version、paper_dossiers.schema_version、selection_progress_version。db_path 是个人路径，反馈前请脱敏。active_tasks 统计前台异步问答和知识写入，不是所有后台任务的总数。

运行包 build-info.json 记录构建时间、后端源码指纹、是否包含本地修改以及 EXE 哈希。本版从当前源码重新编译，不是给旧 ZIP 改名。

常见问题

现象 排查
本地服务未连接 Companion 是否运行，8795 是否仍被旧程序占用，插件地址是否正确
版本过旧 插件与 Companion 都升级，核对 health 而非仅看 ZIP 文件名
按钮和版本没有变化 设置中关闭再开启插件；仅关闭侧栏不生效
筛选耗时较长 查看每轮响应、首段、接收、本地整理耗时；多轮模型调用会叠加
只有合并等待时间 当前模型适配器未启用可分段观测的流式接口，不伪造阶段
证据没有高亮 查看文字层、源文件匹配、快照状态、缺失坐标及重复句歧义
没有“关联本地原文” 入口按条目状态显示；已有有效定位或没有可关联证据时不必显示
卡片暂时没有新知识 查看后台整理状态和提问贡献，候选、失败、无新增是不同状态
入库结果不明或冲突 先刷新核对，保留输入，不反复点赞或确认
供应商认证失败 检查所选服务、独立 Key、模型和账户权限，不自动换到另一付费接口

程序冷启动可能比平时慢。不要因短暂等待同时启动多份服务，也不要删除数据库尝试“重置”。

验证边界

本版进行插件单元测试、TypeScript 构建、后端隔离数据库回归、便携 EXE 新库及重启验证。文档图示另用测试数据检查桌面和窄屏布局。详细结果随本地发布核对报告记录。

没有为了制作本文档调用付费 LLM、发送用户论文或写入个人演示知识。因此这些测试不能证明每家供应商、每个模型或每篇 PDF 的在线效果。图示不是 Obsidian 原生端到端验收，也不会把假模型的回答当真实答案展示。

反馈时提供版本、模式、模型名称、阶段耗时和脱敏错误；不要附 Key、完整个人数据库、私有论文全文或未授权的截图。
