# AuxBrain v0.11.2 安装与升级

## 需要准备

Windows 10/11 x64、Obsidian 桌面版 1.5.0 或以上，以及你本人有权用于此工作流的模型服务账户。先阅读 [服务商与隐私](05-服务商与隐私.md)，不要把供应商选项当作套餐授权。

插件与 Companion 都需要安装。无需安装 Python、Conda，也无需手动建数据库。算法包含在闭源便携程序中，GitHub 自动生成的 Source code ZIP 不是运行包。

## 配套文件

目标发布页：[0.11.2 Beta](https://github.com/asjmasjm/auxbrain/releases/tag/0.11.2)。以实际公开附件为准；发布前请使用随本次交付提供的本地文件。

| 文件 | 用途 |
| --- | --- |
| AuxBrain-Plugin-0.11.2.zip | 手动安装插件，内含 auxbrain 文件夹 |
| main.js、manifest.json、styles.css | BRAT 使用的三个独立插件附件 |
| AuxBrain-Companion-0.11.2-win-x64.zip | 本地算法与数据库服务 |
| AuxBrain-0.11.2-beta-guide.zip | 本套 Markdown、HTML 和图示 |
| SHA256SUMS.txt | 核对以上附件的 SHA-256 |

```powershell
Get-FileHash "$env:USERPROFILE\Downloads\AuxBrain-Companion-0.11.2-win-x64.zip" -Algorithm SHA256
```

将结果与同一次发布的 `SHA256SUMS.txt` 比较，不使用旧教程中的哈希。

## 第一次安装

1. 完整解压 Companion ZIP，运行 `AuxBrain-Companion.exe`，使用插件期间保持服务运行。
2. BRAT 安装：在 Obsidian 安装并启用 BRAT，添加 `https://github.com/asjmasjm/auxbrain`，选择 `0.11.2`，启用 AuxBrain。
3. 手动安装：把插件 ZIP 内的 `auxbrain` 文件夹放到当前 vault 的 `.obsidian/plugins/`，在第三方插件中启用。不要出现 `auxbrain/auxbrain/main.js` 的多余嵌套。
4. 打开带文字层的 PDF 或 Markdown，载入 AuxBrain，按照首次提示配置模型。保存 Key 不自动测试；测试连接需单独点击。

**安全提示：Windows Companion 为未签名 Beta。** SmartScreen 可能拦截。只从确认的来源下载并核对哈希；是否继续运行由用户自行决定，不要全局关闭 SmartScreen 或杀毒软件。单位管理的电脑应遵守管理员策略。

## 从旧版升级

1. 等问答、入库和后台整理完成，退出旧 Companion。
2. 在服务停止后备份整个 profile 目录，包含可能存在的 SQLite 附属文件。
3. 解压新的 Companion，保留原 profile 或自定义 `--db` 参数，启动新版。
4. BRAT 更新插件或替换三个插件文件。BRAT 不负责更新 Companion。
5. 在「设置 → 第三方插件」中关闭再开启 AuxBrain。只关闭侧栏不会重新加载代码。

默认数据库：`%LOCALAPPDATA%\AuxBrain\profiles\default\auxbrain.sqlite`。

默认接口：`http://127.0.0.1:8795`。首次运行自动建库，旧库自动迁移；不需要删除原库。插件要求 Companion 至少 0.11.2 且协议为 1，建议使用本版配套包，不要只升级一端。

进入 [使用教程](02-使用教程.md)。
