# AuxBrain 0.16.2 Beta

本版配套 Companion 0.12.2。插件与运行包分别更新，BRAT 不会自动更新 Companion。

## 论文卡片

卡片与详情显示“已提问 n 次，m 条知识待入库确认”。n 是已关联到该论文档案的提问次数，不保证包含尚未关联的旧提问；m 是该档案中待确认的知识数量，不是当前页的条数。计数尚未同步时明确显示待同步，不填成零。

## 原文关联

在知识条目中点击“关联本地原文”，等待关联结果；成功后使用“跳转已关联原文”。本版可识别跨多个连续文本分段的证据，不再因为单个分段容纳不下整段证据而报告找不到。

跨页 PDF 会显示页码范围，并打开起始页；仅在起始页文字能唯一匹配时高亮该部分。不会把整段跨页证据标成已经全部高亮。文件变更、重复语句或缺少文本层仍会提示无法唯一定位，不会猜测位置。

## 论文图谱

- 论文详情中的“查看本篇论文知识图谱”仅加载这篇论文的已确认实体关系。
- 知识库列表中的“查看全部论文知识图谱”查看全库关系。
- 切换论文会清除旧结果；旧请求晚返回也不会覆盖新论文。
- 尚未建立关系时显示“本篇论文尚未建立已确认的实体关系”。保存了文字知识不等于已产生实体关系，不使用其他论文的图谱补齐。

原有卡片审核方式保持不变。跨论文检索中的共同关键词仍不代表已证实的关系。

## 更新与核对

1. 等待提问、入库及后台整理结束，停止旧 Companion，备份原数据目录。
2. 解压并运行 Companion 0.12.2，保留原 profile 或 `--db` 路径；不要删除数据库。
3. 更新插件到 0.16.2，在设置的第三方插件中关闭再开启 AuxBrain。仅关闭侧栏不会重载代码。
4. 分别打开两篇论文的卡片，核对计数和“本篇论文”图谱，再尝试原文关联。

Companion 0.12.2 同时包含上版前端所需的跨论文检索、用量记录接口。未更新后端时，这些入口会提示升级。用量是“已记录 tokens”，不是完整账单。

Windows 运行包仍为未签名 Beta，可能出现 SmartScreen 警告。仅从项目发布页下载并核对 SHA-256，不要全局关闭系统安全防护。本次更新不自动开启付费后台 LLM。

本地打包不等于已在 GitHub 发布；发布前相应版本下载链接可能不可用。此文档没有把模拟界面截图描述为真实 Obsidian 截图。
