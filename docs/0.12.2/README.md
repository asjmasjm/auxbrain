# AuxBrain v0.12.2：右键入口修复

本版为插件行为更新，版本从 v0.11.2 升为 **v0.12.2**。Companion 没有改动，继续使用 **0.11.2 / API 1**，不需要重启服务或重建数据库。

## 重新加载

在 Obsidian「设置 → 第三方插件」中关闭再开启 AuxBrain。只关闭侧栏不会载入新版代码。

## 从哪里进入

1. 打开 PDF 或 Markdown，在正文/阅读页面右击，选择 **为当前文档载入AuxBrain**。
2. 焦点在右侧大纲或空白侧栏时，也可以右击进入；插件会识别最近使用的阅读标签。
3. 也可在文件列表里右击 PDF/Markdown，从原生菜单进入该文件的 AuxBrain。
4. 面板已经载入但被隐藏时，菜单显示 **打开当前文档的 AuxBrain**，只展开面板，不清空回答。
5. 面板已显示且是当前论文时，不再重复显示载入选项；选中文字仍可 **加入 AuxBrain**。

输入框、设置、无关面板保留原来的菜单。没有打开支持的文档时，不会猜测要分析哪篇论文。问答或写入进行中仍保留互斥保护。

备用入口：左侧 AuxBrain 图标，或 `Ctrl+P` 搜索 **向当前文档提问**。

## 版本规则

- 功能或行为更新：`0.N.P → 0.(N+1).P`，第三段不变。
- 仅重新编译：`0.N.P → 0.N.(P+1)`，第二段不变。
- 例：下一次功能更新为 `0.13.2`；若只是重编译当前版，则为 `0.12.3`。
- 未改动的 Companion 保留真实版本，不给旧二进制改名冒充新构建。

问答、证据与知识库流程沿用 [0.11.2 使用文档](../0.11.2/00-文档导航.md)。旧教程中“两端一起升级”的提醒适用于从更早版本升级到 0.11.2，本次只需要更新插件。
