# AuxBrain 0.13.2 使用变化

本版本更新前端知识库和进度显示。Companion 仍为 0.11.2，无需重启服务；数据库和原有记录不变。

## 个人知识库

- **待整理的原文**：从论文保留的原句，还没有提炼成结论。短预览不是摘要。展开“查看完整原文”可读全文并跳转原文。
- **知识结论**：已经写成结论的条目；是否经过确认由状态单独表示。
- **查看原文依据**：支撑该结论的论文原句，不是另一份摘要。

### 把原文整理成知识

1. 在论文卡片中展开对应栏目，点击“写下我的理解”。
2. 对照原文，在“我的理解”中写出它支持的一个结论，例如“数据集 A 用于训练，数据集 B 用于泛化评测”。
3. 点击“保存我的理解”。原文及历史保留，新结论仍为待核对，不会自动变为已确认。
4. 核对结论及适用范围，点击“确认结论”，再点击“确认结论无误”。有问题则“修改结论”。

原文不再提供直接确认为知识结论的按钮。历史上已确认的原文保持原状态，以“保存的原文”展示，不会悄悄改写。
返回按钮仍位于左上角。分类和适用条件、备注默认收起。空白理解不会发送写库请求。

### 查看已有结论

先看结论，再按需展开原文依据。点击“跳转原文”定位文档；缺少本地位置时，“关联本地原文”仍保留在条目操作区。
定位不唯一或文件已变更时，不会假报定位成功。

## 回答进度

筛选阶段标题改为 **AuxBrain+LLM协同**。不再显示其下面的逐轮等待、首段响应、接收和本地处理耗时。
阶段状态、阶段总耗时和问答整体耗时仍保留。只改变显示，不增加模型调用或修改算法。

## 更新方式

等待正在进行的任务完成，在“设置 → 第三方插件”中关闭再开启 AuxBrain。
仅关闭侧栏不会重载插件。插件设置中应显示 0.13.2。
